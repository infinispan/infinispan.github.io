= Infinispan AI Integrations: Spring AI and LangChain Python

I am very happy to announce two new releases that bring Infinispan closer to the AI ecosystem:
https://github.com/infinispan/spring-ai-infinispan[Spring AI Infinispan] *1.0.0* and
https://github.com/infinispan/langchain-infinispan[LangChain Infinispan] *0.1.0* for Python.

These two integrations are the result of the work we have been doing to make Infinispan
a first-class citizen in the AI world. Infinispan has supported vector search since version 15,
and now we are making it easier than ever to use it from the most popular AI frameworks.

== Spring AI Integration 1.0.0

https://docs.spring.io/spring-ai/reference/[Spring AI] is the Spring ecosystem's answer
to building AI-powered applications in Java. With the release of
https://github.com/infinispan/spring-ai-infinispan/releases/tag/1.0.0[Spring AI Infinispan 1.0.0],
you can now use Infinispan as a backend for two key Spring AI capabilities:

=== Vector Store

Store and search document embeddings using Infinispan's vector search capabilities.
The integration supports cosine, L2 and inner-product similarity metrics,
metadata filtering, and auto-creates Protobuf schemas and indexed caches on startup.
If you have been using Infinispan for caching or data storage, you can now also use it
as your vector database without adding another component to your architecture.

=== Chat Memory Repository

Persist conversation history in Infinispan, enabling stateful conversational AI applications.
User, assistant, system and tool messages are all stored and retrieved, so your chatbot
can remember what was said across sessions.

=== Getting Started

Both modules come with Spring Boot auto-configuration starters. Getting started is as simple
as adding the dependency and pointing to your Infinispan server. For all the details,
check out the link:https://infinispan.org/docs/spring-ai/1.0.0/spring-ai.html[Spring AI integration documentation].

== LangChain Infinispan 0.1.0 for Python

https://www.langchain.com/[LangChain] is one of the most widely used frameworks for building
AI applications, and it has a huge community in the Python world.
With the release of https://github.com/infinispan/langchain-infinispan/releases/tag/v0.1.0[LangChain Infinispan 0.1.0],
Python developers can now use Infinispan as a vector store directly from LangChain.

This means you can store your embeddings in Infinispan, perform similarity searches,
and combine them with all the tools LangChain provides for building RAG pipelines,
agents, and AI-powered applications.

For documentation and usage examples, check out the
link:https://infinispan.org/docs/langchain/stable/langchain.html[LangChain Infinispan documentation].

== Why Infinispan for AI?

If you are already using Infinispan for caching, session storage, or as a data grid, these integrations
let you reuse the same infrastructure for your AI workloads. No need to add yet another database
to your stack.

Infinispan brings several advantages as a vector store:

* *Unified query language* - Ickle combines relational queries, full-text search, and vector kNN in a single language
* *Distributed by design* - kNN queries work across a distributed cluster, with automatic fan-out and result merging
* *Multiple access protocols* - the same indexed cache is accessible via Hot Rod, REST, and RESP (Redis-compatible)
* *Open source* - fully open source under Apache 2.0, part of the https://www.commonhaus.org/[Commonhaus foundation]
